CONTEXT & MOTIVATION

Problem Statement

Threat Landscape & Modern Limitations
  • Suspicious URLs and phishing links are ubiquitously spread via direct links and mobile QR codes.
  • Surface appearance fails to reveal structural attack indicators (e.g. credential masking via @, direct IP hosts, unconventional ports).
  • Existing industry solutions depend heavily on:
    • Opaque, black-box Machine Learning models
    • Live external threat intelligence feeds
    • Live DNS resolutions and network crawlers
    • Cloud API dependencies
The Air-Gapped & Explainability Gap
  • Cloud and DNS-reliant approaches fail in privacy-sensitive, air-gapped, or low-connectivity environments.
  • Neural networks and statistical classifiers output probabilistic scores without causal logical proof.
  • Core Engineering Question:

    • "How can a URL or QR-encoded link be analyzed completely locally using Classical AI techniques and produce an explainable security verdict?"

Focus: Deterministic structural analysis with verifiable causal proof, not probabilistic guessing.
GOALS & ARCHITECTURAL TARGETS

System Objectives

Symbolic Reasoning Objectives
  • 1. Completely Offline Execution: Zero network transmission, DNS queries, or external threat APIs.
  • 2. Lexical Fact Extraction: Deterministically extract positive propositional facts from RFC 3986 components.
  • 3. Horn Clause Knowledge Base: Model cybersecurity axioms strictly as positive definite Horn clauses.
  • 4. Forward Chaining: Apply classical PL-FC-Entails to derive security patterns with full provenance.
  • 5. A* Heuristic Search: Discover brand typosquatting via optimal string edit pathfinding.
Explainability & Practical Delivery
  • 6. Categorical Risk Verdicts: Resolve patterns to discrete categories: SAFE, REVIEW, SUSPICIOUS, HIGH RISK.
  • 7. Explainable Proof Trees: Synthesize causal derivation trees answering "Why was this verdict assigned?".
  • 8. Offline QR Code Decoding: Local 2D matrix extraction providing semantic parity with direct URL entry.
  • 9. Strict Determinism: Identical inputs produce identical facts, proofs, and verdicts every execution.
Every single objective was fulfilled and validated by our automated test suite across 10 engineering phases.

FORMAL REASONING

Knowledge Representation Using Horn Clauses

Definite Horn Clause Structure

Formal mathematical representation:

P₁ ∧ P₂ ∧ ... ∧ Pₙ  ⇒  Q
  • Positive Atomic Literals: Negation ($\neg$) is strictly prohibited in premises and conclusions.
  • Singular Head: Exactly one positive literal in conclusion $Q$.
  • Severity Association: Each rule mapped to immutable severity: CRITICAL, HIGH, MEDIUM, LOW, or NONE.
Example Horn Rule: 
hostname_is_ip_address
∧ path_contains_sensitive_keyword
  ⇒ pattern_credential_harvesting_on_ip [CRITICAL]
Knowledge Base Rule Catalog
  • 🚨 R1: IP + Sensitive Keyword $\implies$ Credential Harvesting [CRITICAL]
  • 🚨 R2: Authority Userinfo ('@') $\implies$ Credential Masking [CRITICAL]
  • ⚠️ R3: Typosquatting + HTTP $\implies$ Insecure Impersonation [HIGH]
  • 🚨 R4: Typosquatting + Sensitive Keyword $\implies$ Targeted Phishing [CRITICAL]
  • ⚠️ R5: Redirect Parameter + Subdomains $\implies$ Obfuscated Redirect [HIGH]
  • 🚨 R6: Double Extension $\implies$ Executable Masquerading [CRITICAL]
  • 🚨 R7: Abnormal Scheme (javascript:, data:) $\implies$ Script Context [CRITICAL]
  • ℹ️ R8: HTTP Insecure Transport (Benign Path) [LOW]
  • ℹ️ R9: Non-Standard Network Port [MEDIUM]
  • ✅ R10: Clean Baseline Profile (11 Clean Indicators) [NONE]
The Knowledge Base holds expert cybersecurity axioms; Forward Chaining mechanically deduces their logical consequences.

SECONDARY AI SEARCH ENGINE

A* Heuristic Search for Typosquatting

State Space & Admissible Heuristic
  • State Representation: $n = (i, j)$ tracking positions in source label and target brand.
  • Cost Function: $f(n) = g(n) + h(n)$
  • Discrete Edit Costs:
    OperationCostEffect
    MATCH0Exact character match
    SUBSTITUTE1Character substitution
    INSERT / DELETE1Length modification
    TRANSPOSITION1Adjacent swap (Damerau)
  • Heuristic $h(i, j)$: $|(|source|-i) - (|target|-j)|$
    Proven Admissible: Single operations alter length discrepancy by at most 1 unit; $h(n) \le h^*(n)$ always!
Execution: g00gle.com $\to$ google
A* Path Search: 'g00gle' vs 'google'
Step 1: MATCH 'g'                      [g=0]
Step 2: SUBSTITUTE '0' -> 'o'          [g=1]
Step 3: SUBSTITUTE '0' -> 'o'          [g=2]
Step 4: MATCH 'g'                      [g=2]
Step 5: MATCH 'l'                      [g=2]
Step 6: MATCH 'e'                      [g=2]
--------------------------------------------
Total Optimal Edit Cost: g(n) = 2
Threshold check: $g(n) \le 2 \implies$ Asserts ground fact: brand_typosquatting_detected

*Exact brand matches (cost 0) do NOT trigger typosquatting.

IMPORTANT: A* does NOT produce HIGH RISK; it produces a ground fact. Forward Chaining reasons about it.

Offline QR Code Pipeline
  1. Local Ingestion: Accepts image bytes (PNG/JPG).
  2. OpenCV Detection: Offline QRCodeDetector isolates finder patterns and decodes matrix.
  3. Validation: Validates URL syntax. Non-URL text is rejected cleanly from security analysis (never marked SAFE).
  4. Routing: Routes decoded URL into analyze_url().
Key Design Principle: QR decoding changes the input method, not the security-analysis logic.
The proof tree guarantees complete transparent provenance; no deduction is invented or hallucinated.

SUMMARY & WRAP-UP

Conclusion, Limitations & Future Scope

Key Accomplishments & Limitations
  • Pure Classical AI: Fully functional symbolic security screening using Horn logic and Forward Chaining.
  • Heuristic Search: Upstream A* string distance with mathematically proven admissible heuristic.
  • Transparent Limitations:
    • Air-gapped: cannot observe server-side dynamic payload delivery.
    • No live DNS or threat feeds (PhishTank/VirusTotal).
    • Typosquatting search bounded by curated local brand lexicon.
    • SAFE indicates absence of local suspicious patterns, not guaranteed remote legitimacy.
Future Research Scope
  • Dynamic Knowledge Base Expansion: Allow analysts to author new Horn rules via JSON without code edits.
  • Regional Brand Lexicons: Integrate larger, localized dictionaries for regional banking and education.
  • Unicode Homoglyph Detection: Symbolic rules for internationalized domain name (IDN) confusable characters.
  • Adaptive QR Preprocessing: Local contrast enhancement for degraded, low-resolution QR codes.
FINAL VIVA LINE: "The goal is not to replace real-world threat intelligence, but to demonstrate how Classical AI can perform transparent, deterministic and explainable security reasoning."
